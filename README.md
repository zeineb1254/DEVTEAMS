# AbsenceFacile — Gestion des absences

Projet pédagogique réalisé avec HTML, CSS et JavaScript.

## Fonctionnalités
- Ajouter une absence (nom, date, type, statut et motif).
- Afficher les absences dans un tableau.
- Rechercher par nom et filtrer par statut.
- Afficher les statistiques : total, en attente et justifiées.
- Supprimer une absence avec confirmation.
- Sauvegarder les données dans le navigateur grâce à `localStorage`.
- Interface adaptée aux ordinateurs et aux mobiles.

## Lancer le projet
1. Ouvrir le dossier dans VS Code.
2. Ouvrir `index.html` dans un navigateur.
3. Optionnel : utiliser l'extension Live Server dans VS Code.

## Limites
C'est une démonstration front-end : les données restent dans le navigateur utilisé. Elles ne sont pas partagées automatiquement entre plusieurs ordinateurs, car le projet n'a pas de serveur ni de base de données.

## Technologies
- HTML5
- CSS3
- JavaScript (DOM, événements, tableaux, localStorage)
